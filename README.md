# `simplefts` — a simple full-text search engine

`simplefts` is a library and command-line application for full-text search. It’s
adapted and extended from [Artem Krylysov’s super fun
tutorial](https://artem.krylysov.com/blog/2020/07/28/lets-build-a-full-text-search-engine/)
(refer also to [the GitHub repo](https://github.com/akrylysov/simplefts)).

Using additional libraries, it can handle some compressed files and, very badly,
PDFs. Improving the PDF support is a goal, but is difficult (hence fun).
